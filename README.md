# Lab4-MusicService

Лабораторная работа №4 по предмету ИППРПО: Интеграция Git и Jenkins. Автоматическая сборка проекта.

## Информация о проекте
- **Предметная область:** Музыкальный сервис (Music Service)
- **Вариант:** 11
- **Индивидуальное задание:** Добавить новый тест для операции с треком или плейлистом, продемонстрировать прохождение теста после автоматического запуска Jenkins.

## Реализация
- В класс `Playlist` и `PlaylistService` добавлен метод `removeTrack` / `removeTrackFromPlaylist` для удаления композиции из плейлиста.
- В класс `PlaylistServiceTest` добавлен тест `testRemoveTrackFromPlaylist_Variant11()`.
- Сборка и тестирование автоматизированы с помощью **Jenkins Declarative Pipeline** и триггера **Poll SCM**.
